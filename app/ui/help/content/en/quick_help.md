# Quick Help - Keyboard Shortcuts

## File
- **Ctrl+N**: New project
- **Ctrl+O**: Load project
- **Ctrl+S**: Save project
- **Ctrl+E**: Export as image
## Edit
- **Ctrl+Z**: Undo
- **Ctrl+Y**: Redo
- **Delete**: Delete selection
- **Ctrl+A**: Select all
## View
- **Ctrl++**: Zoom in
- **Ctrl+-**: Zoom out
- **Ctrl+0**: Reset zoom
## General
- **F1**: Quick help
- **ESC**: Cancel operation
- **Space**: Move view
## Navigation
- **Arrows**: Move selection
- **Ctrl+Arrows**: Move quickly
- **Tab**: Next element
- **Shift+Tab**: Previous element
