# About Asteroid

## Description
Asteroid is a visual workflow editor built with Python and PyQt6, designed for creating interactive diagrams using Tropos and i* methodologies.
![](images/main_interface_example1.png)

## Features
- ✅ Visual node editor
- ✅ Dynamic connections
- ✅ Configurable properties
- ✅ Multi-format export
- ✅ Intuitive and customizable interface

## Technologies
- **Language**: Python 3.x
- **GUI**: PyQt6
- **Project format**: .astr (custom JSON)
- **Rendering**: QPainter
