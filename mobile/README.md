# Asteroid Mobile

## About Asteroid

**Asteroid Mobile 1.0.0** is a touch-first companion for creating Tropos and i* diagrams on the go. These diagrams help model how actors and agents pursue goals, depend on one another, and organize resources, plans, and intentional relationships. The app provides a focused mobile canvas for placing, connecting, editing, and reviewing those model elements.

## Development

This repository contains the Flutter mobile application. Dependencies are declared in `pubspec.yaml`; the project is designed to work with packages available in the local Pub cache when network access is limited.

The mobile editor supports touch-based diagramming, pan and zoom, behavior canvases for actors and agents, properties, undo and redo, validation, local autosave, English and Spanish text, light and dark themes, `.astr` project files, and PNG diagram export.
